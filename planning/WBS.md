# Work Breakdown Structure

1. Project initiation
   - 1.1 Problem statement and stakeholders
   - 1.2 Requirements gathering (survey)
   - 1.3 Process model selection
2. Planning
   - 2.1 WBS and estimates
   - 2.2 Trello board and GitHub repo
   - 2.3 Gantt chart and risk register
3. Design
   - 3.1 DFD Level 0, 1, 2 + data dictionary
   - 3.2 Sequence and state diagrams
   - 3.3 Architecture diagram
4. Development
   - 4.1 Increment 1 – core ordering
   - 4.2 Increment 2 – coupons and payment
   - 4.3 Increment 3 – tracking and admin
5. Testing, ethics, closure
   - 5.1 Testing
   - 5.2 Ethics checklist
   - 5.3 Report, slides, rehearsal

Schedule, owners and risks: `QuickBite_Project_Plan.xlsx`.
